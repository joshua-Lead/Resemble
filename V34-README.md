# RESEMBLE v34 — Account System

Complete frontend account layer for the current RESEMBLE build:

- authenticated dashboard
- profile name editing
- saved delivery addresses with edit/delete
- persistent local order history
- dynamic order confirmation
- protected account and checkout routes
- current cart, wishlist, product and 3D systems preserved

Run `START-RESEMBLE.bat` for the local site.

Note: data is stored in the browser in this version. v35 introduces the backend API for real server-side persistence and multi-device accounts.
