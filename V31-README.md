# RESEMBLE v31 — Cart System

One-click local storefront build. v31 adds a dedicated working bag/cart page with line-item quantity controls, remove actions, live totals, empty-state handling, persistent localStorage cart, and checkout handoff.

Run `START-RESEMBLE.bat` and open the storefront. Add an item from a product page, open BAG, adjust quantity, remove items, and proceed to checkout.
