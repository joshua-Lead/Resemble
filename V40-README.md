# RESEMBLE v40

Live-commerce integration layer on top of v39.

- PostgreSQL-backed persistent state with JSON fallback for simple local runs
- Razorpay Standard Checkout flow with server-created orders
- Server-side HMAC payment signature verification
- Razorpay webhook endpoint with signature validation
- SMTP order confirmation/status notification hooks
- Docker Compose with PostgreSQL
- One-click local and Docker starters
