# RESEMBLE v30 — Product Management

### Included
- Centralized product catalog with stock, active and featured states.
- `admin.html` product management console.
- Create, edit, hide, delete and reset demo products.
- Shop automatically reads active products from the catalog.
- Stock totals and low-stock counts in the admin console.
- Catalog persisted in browser localStorage for this frontend-only stage.
- Existing cart and 3D motion systems preserved.

### Run
Double-click `START-RESEMBLE.bat`, then open:
- Store: http://127.0.0.1:5500/
- Product management: http://127.0.0.1:5500/admin.html
