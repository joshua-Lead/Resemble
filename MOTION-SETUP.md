# RESEMBLE v27 — 3D Motion Integration

This build merges the V25 motion assets into the V27 frontend.

## Live 3D
- Homepage: Three.js RESEMBLE emblem
- Product page: Three.js garment viewer hooks
- GLB/GLTF loader asset retained
- Motion CSS and interactive effects retained

## Browser requirement
Three.js is loaded from jsDelivr, so the browser needs internet access for the 3D libraries.
