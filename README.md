# RESEMBLE — v28 Production Foundation

## One-click local run
1. Double-click `START-RESEMBLE.bat`.
2. Browser opens at `http://127.0.0.1:5500/`.
3. Use `STOP-RESEMBLE.bat` to stop the local server.

This build keeps the current RESEMBLE visual system and 3D motion assets while cleaning duplicated script loading and adding a zero-install (Python-required) local launcher.
