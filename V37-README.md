# RESEMBLE v37 — Checkout + Payment + Notifications

Adds a production-shaped checkout flow with shipping validation, payment authorization API, COD/UPI/card methods, real server-side order creation, stock validation, persistent order records, and confirmation details.

Default mode is `demo` so the project works immediately with one click. Set live payment credentials only after adding the merchant/provider server adapter.

Start: `START-RESEMBLE.bat`
