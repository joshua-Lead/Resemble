# RESEMBLE v33 — Authentication System

One-click local client authentication layer built on top of v32.

## Includes
- Sign in / create account flow
- SHA-256 password hashing via Web Crypto
- Persistent local browser session
- Protected Account + Checkout pages
- Sign out
- Client name, email and client ID on Account
- Wishlist, cart and 3D systems preserved

## Note
This is a functional frontend/local authentication layer. For production, replace localStorage auth with a secure server-side auth provider and database.
